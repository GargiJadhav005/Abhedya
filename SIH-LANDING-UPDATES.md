# SIH 26251 Landing Page Updates

## What Changed

The landing page (`src/routes/index.tsx`) now reflects the **SIH 26251 Predictive Logistics Decision System** positioning from the solution document. Changes are minimal and targeted to communicate the core differentiation clearly.

---

## Key Updates

### 1. Hero Section
**Before:**  
> "BEFORE THE MISSION. BEYOND THE SHORTAGE."  
> "At the edge of the map, readiness is not an option. It is the supply line that never breaks."

**After:**  
> "PREDICT THE NEED. PREVENT THE SHORTAGE."  
> "Network-aware logistics intelligence that forecasts supply needs, checks delivery feasibility, traces disruption impact, and recommends where limited resources should be deployed first."

**Impact:** Immediately establishes the system goes beyond prediction to proactive prevention with network awareness.

---

### 2. Section 01: Connected System → Network-Aware Prediction
**Before:**  
> "One network. Every decision in context."

**After:**  
> "One disruption. Many consequences."  
> "NEXUS represents posts, depots, routes and transport as a connected network. When a route fails or a depot runs low, the system traces how that disruption propagates and which locations will be affected next."

**Impact:** Introduces **disruption propagation** — a core USP.

---

### 3. Section 02: Five Intelligence Pillars → Five Decision Capabilities
Renamed pillars to match the **Predict → Check → Bottleneck → Propagate → Prioritize → Prevent** workflow:

| Old Pillar | New Capability | Key Change |
|---|---|---|
| 01 — ANTICIPATE | **PREDICT NEEDS** | "See the shortage before it happens" |
| 02 — UNDERSTAND | **CHECK DELIVERY** | "Can we actually deliver it?" — feasibility check |
| 03 — COMPARE | **FIND BOTTLENECK** | Identifies constraint: inventory, transport, route, dependency |
| 04 — AUTHORISE | **TRACE IMPACT** | **NEW:** "How will failure propagate?" — network impact |
| 05 — DECIDE | **PRIORITIZE RESOURCES** | "Where should we act first?" — dynamic prioritization with resilience score |

**Impact:** Makes the **5 strong USPs** from the solution doc visible and easy to understand.

---

### 4. Section 04: Intelligence to Action → Prediction to Prevention
**Before:** Observe → Predict → Evaluate → Authorise → Execute → Learn

**After:** **Predict → Check → Find Bottleneck → Trace Impact → Prioritize → Prevent**

**Impact:** Directly maps to the solution's core process. "Prevention" is the end goal, not just "execution."

---

### 5. Final CTA
**Before:**  
> "Move from reacting to anticipating."

**After:**  
> "Prevent shortages before they happen."  
> "Network-aware logistics intelligence that answers: What will we need? Can we deliver it? What could fail? How will failure propagate? Where should limited resources go first?"

**Impact:** Reinforces the **5 key questions** the system answers — the differentiation from basic predictive systems.

---

### 6. Meta Tags
- **Title:** "NEXUS | Predictive Logistics Decision System"
- **Description:** Includes "SIH 26251" and the full value proposition
- **OG Description:** "Predict the need. Check the feasibility. Trace the impact. Prevent the shortage."

This is the exact positioning from **Section 6** of the SIH solution document.
